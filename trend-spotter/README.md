Trend Spotter

Trend Spotter is a modern and interactive web project exploring the evolution of fashion, music, and streetwear trends from the 1990s to the present day.

✨ Features

- Responsive design
- Semantic HTML5
- Modern CSS3 styling
- Smooth animations and transitions
- Interactive JavaScript functionality
- Modal window
- Gallery section
- Timeline of trends
- Contact form

🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Git
- GitHub

📚 Purpose

This project was created to practice front-end development by building a modern, responsive, and interactive website using HTML, CSS, and JavaScript.
